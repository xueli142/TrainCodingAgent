# icefox-agent 项目说明

一个用 **TypeScript** 写的极简 AI 编码 Agent CLI：通过「模型 + 工具调用循环」来读写文件、搜索代码、执行命令。

## 怎么跑

```bash
pnpm start                 # 进入交互式对话（tsx 直接跑 TS）
pnpm start -- --sessions   # 查看历史会话
pnpm start -- --resume     # 恢复最近一次会话
pnpm start -- --trace      # 记录每轮请求上下文（排查用）
```

## 核心结构

```
src/
├─ index.ts              # 入口：REPL 循环、会话恢复
├─ agent_loop.ts         # ★ 主循环：模型 → 工具 → 回灌 → 再请求
├─ anthropic-adapter.ts  # 模型适配器（Anthropic 协议）
├─ prompt.ts             # 系统提示词
├─ permissionManager.ts  # 权限审批（路径 / 命令 / 编辑）
├─ session.ts            # 会话存储（append-only jsonl）
├─ tools/
│  ├─ index.ts           # 工具注册表
│  └─ tool/              # 标准工具集（read/write/edit/bash/glob/grep ...）
└─ utils/                # 错误处理、超长输出落盘
```

## 工作原理

1. 用户在终端输入一句话，进入 `agentloop()`
2. 把消息发给模型（`model.next`）
3. 如果模型要调用工具 → 执行工具 → 把结果塞回消息 → 再问模型
4. 直到模型给出纯文本回复，打印给用户

## 工具集（共 11 个）

`read` / `write` / `edit` / `bash` / `glob` / `grep` / `todowrite` / `question` / `skill` / `task` / `webfetch`

安全约束：所有路径限制在 cwd 内；改文件前必须先 `read`；危险命令要审批；超长输出落盘只留预览。

## 数据目录

统一放在 `~/.ICEFOX-code/`：会话、权限决策、技能、工具输出、trace。
