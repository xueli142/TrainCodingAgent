## 一、项目目标与已确立的核心原则

学习目标：手写一个最小可用的编码 agent CLI（TS + Anthropic 协议）。全程遵守三条已达成共识的设计原则：

1. **事实与视图分离**：盘上事件 = 发生过的全部事实（append-only）；模型上下文 = 现场投影（可变环境每次重建）
2. **渐进式披露**：catalog(name+一句)进 system 头、input_schema 走 API tools 参数、skill 正文/SKILL.md/task 子代理/截断输出只在调用后进入 tool_result（"索引→正文"两级）
3. **schema 单源**：zod 为唯一真相，`z.toJSONSchema`（jsonSchemaOf，剥 $schema）生成 wire schema；手写 JSON 双源已被消灭

## 二、已落地文件清单（全部经过冒烟验证）

### 运行时
- `src/index.ts` — REPL 入口；启动参数 `--sessions` / `--resume [id]`；trace 默认开（`ICEFOX_TRACE=0` 关）；回合内 before/after 调 `permissions.beginTurn/endTurn`；回合边界调 `maybeCompactContext`；`/sessions`、`/resume <id|序号>` 对话内切换（切换前打印旧会话投影预览，写 `session_switch` 事件，新会话写 `context_snapshot`）
- `src/agent_loop.ts` — **合约（重要，勿回退）**：所有新消息**就地 push 进 args.messages 共享数组**；返回值=仅增量 `added`（caller 不得再 push 回）；同 (tool,input) 第 3 次起注入 `[loop-guard]` 并标 is_error；maxSteps 默认 30；progress 只认显式 `kind==='progress'`（推断式启发曾导致连环重复调用，已删）
- `src/environment.ts` — ProcessEnvironment（平台/shell 种类/node/home/dataDir）+ ProjectEnvironment（root=.git 探测/slug/trusted@trust.json/storeDir/skillsDir）；`renderEnvironmentBlock(proc, project, MODEL)` 进 system（含模型身份行）
- `src/compact.ts` — 简易压缩：chars/3.5 估算，≥64K 窗口×0.85 触发，固定头(system/tool)+尾 10 保留，中间段 fake-transcript→小调用摘要→`context_summary` 消息；失败=原引用 no-op；tail 起点回拉防孤儿 tool_result
- `src/context-tracer.ts` + `src/inspect-trace.ts` — 每次 next() 前记录完整请求四件套（system 全文/messages 线块/tools description+schema 全文）到 `~/.ICEFOX-code/traces/<ts>-<sid>.jsonl`；查看：`npx tsx src/inspect-trace.ts [--turn N] [--raw] [--tools|--tools-all] [--diff]`

### 存储（事件溯源）
- `src/session.ts` — `~/.ICEFOX-code/projects/<slug>/<sessionId>.jsonl`；事件形状 `{id,seq,parent,cwd,type,ts,message|null,data?}`；13 种 type（8 对话 + rename/context_snapshot/turn_end/error/session_switch）
  - 写：`saveMessages`（跳过 system/tool 两类现场构建物；按 message.id 幂等）、`appendSessionEvent`；**写锁 withStoreLock** 串行化 seq/parent 计算；`appendRawEvents` 单批单 write+fsync + **尾行修复守卫**（末字节无 \n 先补，半行隔离后由 parser 丢弃，历史不清写）
  - 调度：`scheduleSave` 粘滞 job（1s tick，长度没变跳过）+ `flushSessionSaves`（/exit、SIGINT）
  - 投影：`projectMessages` = 从最后一条 summary 截断起播 → **存 8 读 3**：只出 user/assistant(非空)/tool_result 降维文本(`[tool x result]\n...`，25K 截断,ERROR 标记)/context_summary/snip 标记；thinking/progress/tool_call/全部控制事件不进上下文；**id 锚点必留**（恢复→续聊→重存 0 新增的幂等靠它）；snip 语义=投影层隐藏+标记挪回原位
- 打标归属（已共识）：type/seq/parent 由 host 代码打，模型碰不到事件元数据；summary 类经独立小模型调用；主 agent 无历史改写权

### 工具层 `src/tools/tool/`（11 个 opencode 同名标准 + 3 共享件）
- registry：`src/tools/index.ts` **import 时自动 initRegistry**（勿依赖调用方记得 init——踩过坑：忘 init 导致 tool-not-found 静默全失败）；`getToolSchemas()`（API 参数用全量）与 `buildToolCatalogMessage()`（role:'tool' 目录消息，只含 name+description 首行）双通道
- read/write/edit + `read-state.ts`：先 read 才能 edit/write，外部改动强制重读；write/edit 走 `file-review.ts applyReviewedFileChange`（diff→ensureEdit→写）
- bash：win=PowerShell 路径、超时杀树、exit-code 传播、tail 截断（2000 行/50K）；描述已含动态 `OS/shellKind` 行；命令按段过 `ensureCommand`
- glob/grep：`fs-walk.ts` 自研 glob→RegExp（**`*` 不跨 `/`，`**/` 才跨**）+ SKIP_DIRS；limit 100/200 匹配
- question/task：**setter 注入模式**（`setQuestionHandler/setTaskExecutor`），未接线返回可重试错误文案；skill.ts 已实现 `discoverSkills`(`.icefox/skills`+`~/.ICEFOX-code/skills`)+`formatSkillsForPrompt`（**索引进 system 尚无人调用**）
